# Módulo 9 — Dashboard Ejecutivo Final

## Descripción
Entrega del Checkpoint 9 del curso "IA & Automatización · Excel": dashboard 
ejecutivo interactivo construido sobre el motor de análisis de módulos anteriores.

## Archivos
- `DashboardFinal_DiBariMateo.xlsx`: archivo principal con el dashboard.
- `Analisis_IA_Prompts_DiBariMateo.pdf`: análisis de IA (abogado del diablo) y prompts utilizados.

## Cómo abrir
Abrir `DashboardFinal_DiBariMateo.xlsx` con **Excel de escritorio** (no Google 
Sheets ni Excel Online), habilitando contenido/conexiones de datos si Excel lo solicita.

## Contenido por criterio de la consigna
- **Hoja "Dashboard_Final"**: interfaz limpia, hojas de soporte ocultas.
- **Tarjetas KPI**: parte superior del dashboard, con formato condicional (semáforo).
- **Gráficos + 3 slicers interconectados**: gráficos dinámicos con segmentadores 
  de Región, Meses y Categoría, todos conectados a las tablas vía Conexiones de informes.
- **Gráfico de Cascada**: comparación Meta vs Ventas por categoría.
- **Capa narrativa**: títulos y texto dinámico con los hallazgos principales.
- **Análisis de IA**: ver `Analisis_IA_Prompts_DiBariMateo.pdf` — incluye 3 
  conclusiones, revisión crítica y los prompts usados.
